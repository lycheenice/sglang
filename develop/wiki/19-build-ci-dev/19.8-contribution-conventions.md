# 19.8 贡献约定

## 定位

SGLang 用 `.claude/skills/`（流程教程）+ `.claude/rules/`（代码风格守卫）+ `.pre-commit-config.yaml`（本地/CI 钩子）三层约束贡献质量。skills 是"怎么做某类任务"的 step-by-step 指南，rules 是"改这类文件必须遵守"的硬规则，pre-commit 在提交时跑 isort/ruff/语法检查。

## 职责

- `.claude/skills/`：21 个 skill，覆盖内核/配置/观测/网关/CI/测试/重构/命名等流程（详见各子系统页）。重点：`large-class-style`（Scheduler/TokenizerManager/ModelRunner 风格）、`mechanical-refactor-verify`（机械重构可验证）、`sglang-runtime-context`（配置/运行时）、`env-var-conventions`（环境变量）、`speculative-naming`（投机解码命名）、`scripted-runtime-notes`（脚本运行时）、`ci-workflow-guide`/`write-sglang-test`、`add-jit-kernel`/`add-sgl-kernel`、`debug-*`/`generate-profile`/`clean-startup-log`、`sglang-bisect-ci-regression`/`sglang-cherrypick`/`sglang-prod-incident-triage`、cookbook-*。
- `.claude/rules/`：7 条硬规则——`no-dataclasses.md`（用 `msgspec.Struct`）、`general-code-style.md`、`forward-batch-init-new-purity.md`、`modify-component-must-read.md`、`no-getattr-defensive.md`、`schedule-batch-out-of-place-mutation.md`、`unit-test-admission.md`。
- `.pre-commit-config.yaml`：`pre-commit-hooks`（trailing-ws/eof/yaml/toml/ast/large-files/merge-conflict/private-key/debug-statements/no-commit-to-branch）、`isort`、`ruff`（`--select=F401,F821,UP037 --fix`）。

## 关键文件

| 文件 | 角色 |
|---|---|
| `.claude/skills/large-class-style/SKILL.md` | Scheduler/TokenizerManager/ModelRunner 风格 |
| `.claude/skills/mechanical-refactor-verify/SKILL.md` | 机械重构可验证 |
| `.claude/skills/sglang-runtime-context/SKILL.md` | 配置/运行时上下文 |
| `.claude/skills/env-var-conventions/SKILL.md` | 环境变量约定 |
| `.claude/skills/speculative-naming/SKILL.md` | 投机解码命名 |
| `.claude/skills/scripted-runtime-notes/SKILL.md` | 脚本运行时 |
| `.claude/rules/no-dataclasses.md` | 用 `msgspec.Struct` 不用 `@dataclass` |
| `.claude/rules/general-code-style.md` | 通用风格 |
| `.claude/rules/forward-batch-init-new-purity.md` | ForwardBatch init 纯度 |
| `.claude/rules/modify-component-must-read.md` | 改组件必读 |
| `.claude/rules/no-getattr-defensive.md` | 禁防御 getattr |
| `.claude/rules/schedule-batch-out-of-place-mutation.md` | ScheduleBatch 非就地改 |
| `.claude/rules/unit-test-admission.md` | 单测准入 |
| `.pre-commit-config.yaml` | 本地/CI 钩子 |

`no-dataclasses.md` 规定新数据容器用 `msgspec.Struct`（支持 frozen/omit_defaults/kw_only，mul$lang 友好），新代码禁 `dataclasses.dataclass`/`attrs`，旧 `@dataclass` 继续保留、编辑时机会性迁移。ruff 仅选 `F401`（未用 import）/`F821`（未定义名）/`UP037`（注解现代化）三规则并 `--fix`，覆盖 `benchmark/`/`docs_new/`/`examples/`/`python/sglang/`/`sgl-model-gateway/py_*`/`test/`。

## 约束流

```mermaid
flowchart TD
    CONTRIBUTOR["贡献者"] --> SKILL[".claude/skills/<task> 流程指南"]
    CONTRIBUTOR --> RULE[".claude/rules/<pattern> 风格守卫"]
    SKILL & RULE --> CODE["写/改代码"]
    CODE --> PC[".pre-commit-config.yaml 本地钩子"]
    PC --> ISO["isort"]
    PC --> RUFF["ruff F401/F821/UP037"]
    PC --> HOOKS["pre-commit-hooks"]
    PC --> CI["19.3 CI lint.yml"]
    RULE -.被 agent 加载.-> CODE
    SKILL -.被 agent 加载.-> CODE
    NO_DC["no-dataclasses"] -.msgspec.Struct.-> CODE
    TEST["unit-test-admission"] -.准入.-> TESTDIR["test/registered"]
```

贡献者按对应 skill 的流程操作（如加内核走 `add-jit-kernel`/`add-sgl-kernel`），代码须遵 `.claude/rules`（如新数据容器用 `msgspec.Struct`）。提交时 pre-commit 跑 isort/ruff/hooks；CI `lint.yml` 再次校验。改大类（Scheduler/TokenizerManager/ModelRunner）须先读 `large-class-style`；机械重构须按 `mechanical-refactor-verify` 验证。
